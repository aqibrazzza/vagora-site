# Vagora website — project record

This file is the durable record of the v6 rebuild: what exists, why, what is frozen, what is pending. Read this first in any new session. `DIRECTION.md` holds the art direction; `README.md` holds run instructions.

## 1. What the project is

A single-page marketing site for Vagora, an in-store 3D try-on mirror sold to retailers. Audience: founders and merchandising directors. Lives in `D:\website-vskill` as a Vite project.

```
index.html               the page (all copy lives here)
src/main.js              behaviour: Lenis + GSAP ScrollTrigger, intro, reveals, floor state machine, Act two ledger state machine, dock spy, cursor, copy button
src/modules/split.js     accessible word/line splitter (keeps an unsplit visually-hidden name; honours authored <br>). Each `.split-line` is the reveal mask with a glyph safety area (0.1em top / 0.16em bottom / 0.07em inline, margins compensating) and opens to `overflow: visible` once the heading is in (or motion is reduced), so no resting glyph is ever cropped
src/styles/main.css      foundations (tokens) + every chapter's styles, in page order
assets/                  brand, fonts (Switzer + FFL licence; Fragment Mono + OFL), imagery (concept renders), intro film — Vite bundles what is referenced
public/                  robots.txt, share-card.jpg (files that must keep their exact path)
vite.config.js           base "./" so dist/ deploys from any path; gsap+lenis in one chunk
dist/                    build output (ignored by git)
```

Run: `npm install`, `npm run dev`, `npm run build` (→ `dist/`), `npm run preview`.

Narrative: ACT ONE · ON THE FLOOR (what the shopper experiences) → THE VAGORA MIRROR (the physical product connecting experience and business; not an act) → ACT TWO · IN THE BUSINESS (what the retailer gets back). Tonal progression: white → `#0F0F0F` (the Mirror chapter) → pure `#000000` reserved for the closing chapter. Product noun: “the Vagora Mirror” — never unit, kiosk, terminal, station.

Legacy from v5 still in the folder and **not used by the build**: `tokens/`, `reference/` (internal reference surfaces that need `tokens/`), and `src/modules/hero-gl.js` (dead file from the removed WebGL hero — delete it). `assets/` is shared and stays.

## 2. Evidence rules (do not break)

- No customer, store, pilot result, uplift figure, testimonial, avatar or logo wall appears anywhere: none is evidenced yet.
- The console panel shows sample data and is labelled "Illustrative" on the asset and "Sample data, not a live estate." beneath it; its accessible name says so too.
- Imagery is concept renders of the Mirror (noted in a source comment, not on the page — the footer line was removed by request). `mirror-screen-scene.jpg` and `vagora-mirrror.jpeg` are no longer referenced and can be deleted.
- Copy is the client's; product claims are not to be rewritten or invented.
- Icons: Solar (CC BY 4.0) inlined as SVG symbols. Fonts: Switzer (Fontshare FFL) for everything Vagora says; Fragment Mono regular (OFL 1.1, self-hosted latin woff2 from the `@fontsource/fragment-mono` 5.3.0 package, licence in `assets/fonts/FragmentMono-OFL.txt`) for the micro language only.
- Before launch: `og:image` and `rel="canonical"` must become absolute URLs (marked in `index.html`).

## 3. Foundations (approved, refinement 02)

All in `:root` at the top of `main.css`. No second system exists; every component references these.

- **Colour** — monochrome. Light: `#FFFFFF` surface (`#F7F7F6` `--surface-object` / `data-surface="object"` exists as a token but is currently unused — the Mirror chapter moved to `#0F0F0F`), `#0F0F0F` ink, secondary 62%, muted 45%, rule 10%. Dark: `#000000`, white, 68%, 45%, 14%. Every other tone (frost, media ground, control hover, dock wash) is an alpha of ink or white. Status hues exist only for the console pills. `[data-surface="dark"]` re-resolves the aliases (`--bg --text --text-2 --text-3 --line --control-*`) and steps weights down one.
- **Type** — Two voices. **Fragment Mono** (`--mono`, regular only) is the micro language: one 14px tier, weight 400, 0.055em tracking on uppercase labels / 0.045em on indexes, applied to every `.eyebrow` and, via `.notation`, to indexes, RETAIL IMPACT labels, specification and FAQ indexes and console metadata. **Switzer** carries everything else. Headline roles, largest to smallest — the visual object in each composition decides how loud the type is, not the HTML level: **display** `clamp(3.75rem, 1.5rem + 7.5vw, 10rem)` (160 max — the closing “See it in your store.” and the curtain count); **lead** `clamp(2.625rem, 1.5rem + 3.33vw, 5.25rem)` (84 max — the manifesto proposition); **chapter** `clamp(2.25rem, 1.4rem + 2.6vw, 4rem)` (64 max — the two act openings, `.floor__title` / `.business__title`); **section** `clamp(1.75rem, 1.2rem + 1.6vw, 3rem)` (48 max — `.h2`/`.h3`: the Mirror, the Console, Before you commit). Then **feature** ~22px (body tier, weight 500: act feature titles and FAQ questions), **copy** ~17px (small tier: descriptions, impact sentences, the Mirror paragraph, FAQ answers, the console paragraph) and **micro** 14px mono. Body tier 18→22 and small 16→17 are unchanged. Weights 500 light / 450 dark; body 400.
- **Gutter** — `--page-x: clamp(1.5rem, 1rem + 1.1vw, 3rem)` (32px @1440, 38 @2000, 48 max). No global max-width anywhere; reading limits `--reading-max 42rem` / `--copy-max 30rem` apply to copy only.
- **Space** — 8·12·16·24·32·48·64·96·128·160 (`--space-1..10`); section rhythms sm/md/lg.
- **Geometry** — `--radius-media: 0`, `--radius-control: 8px`, `--radius-pill: 999px`. Device frame keeps its hardware radii (14/9px).
- **Motion** — 180 / 320 / 700ms, `cubic-bezier(0.22, 1, 0.36, 1)`. Signature choreography (reveal 900ms, dock arrival 480ms, dock flip 520ms) keeps authored timings. `prefers-reduced-motion`: no Lenis, no curtain, no scrub, poster instead of film, instant states.
